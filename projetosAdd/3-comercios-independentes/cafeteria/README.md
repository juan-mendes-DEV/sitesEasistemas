# GRÃO — Pedidos

Projeto independente em HTML, CSS e JavaScript, sem dependências ou build.

## Executar
Abra index.html no navegador ou sirva esta pasta com um servidor estático.

## Integrar em outro projeto
Copie esta pasta inteira para um diretório próprio e crie um link para seu index.html. Os caminhos dos assets são relativos. Para integrar em um framework, adapte a página e isole o CSS, que utiliza seletores globais.

## Funcionalidades
Cadastro, edição, exclusão com confirmação, busca, filtros e indicadores automáticos. Pedidos com quantidade, preço e avanço de status.

## Dados
Os registros de demonstração são carregados na primeira abertura. A persistência usa localStorage com chave exclusiva `portfolio-cafeteria-v1`. Não há backend, autenticação ou sincronização entre dispositivos. Dados de exemplo são fictícios.
