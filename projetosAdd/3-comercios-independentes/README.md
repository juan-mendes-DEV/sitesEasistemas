# Três sistemas independentes

- cafeteria/ — GRÃO: pedidos de cafeteria, tons de café e creme.
- barbearia/ — CORTE & CIA: agenda para uma cadeira, grafite e verde lima.
- loja-roupas/ — NUVEM: estoque de moda, lavanda e branco.

Cada pasta é um projeto autônomo com index.html, styles.css, app.js e README.md. Não existe painel compartilhado, biblioteca externa ou dependência entre os sistemas. Abra o index.html de cada pasta. Para integrar em outro projeto, copie cada pasta mantendo os três arquivos juntos.
